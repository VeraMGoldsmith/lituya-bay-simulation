# Experiment presentation previews

Presentation-only views of the completed speed-limit × grid-resolution experiment.
The figure and comparison table were approved for inclusion in the root README.
Original records, research reports and archived figures are unchanged. No
simulation, new metric or additional experiment is used.

- [Run-up figure](runup_grid_comparison.png): the three speed limits on two grids, with
  separate curves for the original and finer grids. The x-axis uses the actual
  numerical spacing of 50, 100 and 200 m/s. Heights use unrounded recorded values;
  labels show two decimals. Connecting lines join the tested cases, without
  implying simulations at intermediate limits. Colors identify grids, not accuracy.
- [Comparison table image](secondary_comparison.png) and
  [HTML version](secondary_comparison.html): the seven existing quantities across
  all six follow-up simulations, alongside the earlier original-grid 100 m/s simulation.
  The two studies' time-stepping settings are explicitly distinguished in the
  accompanying methods note. Run-up is displayed to two
  decimals, depths/gauge peaks to three and area to six; exact values are retained
  in HTML data attributes and [provenance.json](provenance.json).

The [presentation notes](presentation_notes.md) contain the figure definition,
table explanation, adaptive time-stepping comparison, detailed methods and the
proposed interpretation paragraph for review. They are generated by the rendering
script, separately from the root README. Detailed verification and excluded-case
information remain in the linked research documentation.

Sources are the committed full-precision CSV/JSON records in
[`experiments/speed-limit-grid-resolution`](../../../experiments/speed-limit-grid-resolution/README.md),

## Regenerate

With the existing Python/Matplotlib environment, run from the repository root:

```sh
python -B docs/presentation/experiment_visuals/render.py
```

The script requires Git and checks every source file against the current commit
before rendering. It refuses modified source records. It records the commit,
input/output hashes, exact plotted/table values, policies, script hash and
rendering version. It modifies only the new presentation outputs.

The following uses the already installed, pinned Docker image, without network
access, installation or image pulling. Git metadata and the repository are
mounted read-only; only the preview output folder is writable:

```sh
task_repo="$PWD"
task_git_common="$(git rev-parse --path-format=absolute --git-common-dir)"
task_image=sha256:e34a83602d2ed2abaad337aa2a4b97a5f6e84b8f801de5fb6cc40f714d7027d4
docker run --rm --pull never --network none --read-only \
  --tmpfs /tmp:rw,exec,nosuid \
  -e PYTHONDONTWRITEBYTECODE=1 -e MPLCONFIGDIR=/tmp/mpl \
  --mount "type=bind,source=$task_repo,target=$task_repo,readonly" \
  --mount "type=bind,source=$task_git_common,target=$task_git_common,readonly" \
  --mount "type=bind,source=$task_repo/docs/presentation/experiment_visuals,target=/render" \
  --workdir "$task_repo" --entrypoint python "$task_image" -B \
  docs/presentation/experiment_visuals/render.py --output /render
```

Both PNGs were visually inspected for readable labels and clipping. Automated
checks confirm six accepted cases, CSV/JSON consistency, the archived control,
exact plotting coordinates/heights, and all 49 displayed table values. The HTML
table received structural/data checks; no browser-based visual review is claimed.
The existing technical report's previously recorded HTML-review limitation is
unchanged.
